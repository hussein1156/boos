# boos — موقع Coach Bossy

نسخة فرونت إيند خالصة من نفس الموقع بنفس التصميم:
**Next.js + TypeScript + Tailwind CSS + Framer Motion**.

## التشغيل

```bash
npm install
npm run dev
```

وبعدها افتح: <http://localhost:3000>

## عايز تعدّل حاجة؟

كل المحتوى في ملف واحد: **`src/boos.ts`**

- **الروابط**: `socials` — إنستجرام، تيك توك، واتساب، فيسبوك، لينكدإن (الأيقونات في آخر الصفحة وفي الهيدر).
  - اللي بيفضّل رابط = الأيقونة بتظهر مطفية لحد ما تملاه.
- **خلفية الصفحة الأولى**: حط صورة في `public` واكتب مسارها في `site.heroPhoto`
  (مثال `"/hero.jpg"`) — بتغطي الصفحة الأولى بالكامل. سيبها فاضية = تدرّج غامق.
- **الصور**: ارفعها في مجلد `public` وحط مسارها مثل `"/about.jpg"` في:
  - `site.aboutPhoto` و `gallery` و `videos[].thumb` و `site.instapayQr`
- **النصوص والباقات**: `site` و `packages` و `videos`.

## اللغات (عربي / إنجليزي)

- الزرار في الهيدر بيغيّر اللغة، والصفحة كلها بتترجم وبتتعكس (RTL) على طول.
- الاختيار بيتحفظ في المتصفح، فبيفضل زي ما سيبتو.
- **كل النصوص في `src/lib/i18n.ts`** — عدّل أي كلمة عربي أو إنجليزي من هناك.
- لو عايز تكتب عربي لأي باقة أو فيديو: استخدم الحقول اللي في آخر الاسم
  زي `nameAr` و `descriptionAr` و `featuresAr` جوه `src/boos.ts`.


## تنظيم الكود

```
src/
├── boos.ts               ← كل المحتوى والروابط (عدّل هنا)
├── app/
│   ├── layout.tsx        ← الخطوط والـ metadata
│   ├── page.tsx          ← تركيب الأقسام
│   └── globals.css       ← الألوان والتنسيقات العامة
├── components/
│   ├── Header.tsx        ← الهيرو
│   ├── Ticker.tsx        ← الشريط المتحرك
│   ├── About.tsx         ← قسم التعريف
│   ├── Stats.tsx         ← الأرقام
│   ├── Gallery.tsx       ← معرض الصور
│   ├── Videos.tsx        ← الفيديوهات + نافذة التشغيل
│   ├── Packages.tsx      ← الباقات وطرق الدفع
│   ├── Footer.tsx        ← الفوتر بالايقونات
│   ├── SectionHeader.tsx ← عنوان القسم + اسم الكوتش (يرجعك لفوق)
│   ├── SocialButtons.tsx ← ايقونات السوشيال (5)
│   ├── PhotoSlot.tsx     ← إطار الصور
│   ├── Reveal.tsx        ← حركة الظهور
│   └── CountUp.tsx       ← عداد الأرقام
└── lib/
    └── video.ts          ← إستخراج رابط يوتيوب
```

## نشر الموقع

موقع ستاتيك خالص — `npm run build` وبعدها ارفعه على Vercel أو Netlify أو GitHub Pages.
